## 真实 LLM 复验

模型：`minimax-m3`。输入为虚构素材，不包含真实用户对话。

素材包含三个独立事实：接口测试通过、部署因缺环境变量受阻、闲鱼商品三选一但尚未上架。

### 抽取

- 延迟：6.4 秒与 7.7 秒；
- 两轮均抽出 3/3 条；
- 类型均正确：done / pitfall / decision；
- 没有把“明天试卖”写成“今天已上架/已有收入”；
- `source_agent=codex` 与 `ingestion_method=transcript-scan` 分开保存；
- Mobius 缓存不可用时三条均保守落自由任务，没有编造 issue。

### 整理

- 第一轮：纯 LLM，69.7 秒；Done / In Progress / Blocked 分区正确；首稿口播过短后扩写到 224 字；
- 第二轮：日报 LLM 成功，口播扩写请求超时，暴露原兜底稿仅 68 字；
- 修复：确定性兜底稿现在复用任务状态与原始进展，并强制落在 persona 的字数区间；对应回归测试通过；
- 无新事实时报告指纹命中，不重复调用 LLM；事实、归属、修订或任务状态变化会标脏。

## Mobius OAuth 复验

同一份既有配置在本轮开始时显示：`connected=true`、`auth=oauth`、`refreshable=true`。

- 初次同步：Mobius 返回 HTTP 401；
- 新增恢复路径：只对 OAuth 401 强制 refresh 并重试一次，不把超时/协议错误误判成认证问题；
- 强制 refresh：授权服务器返回 400，证明当前 refresh token 也已失效；
- 当前动作：重新运行 `mobius_login`，由用户在浏览器授权，再验证同步数量和缓存时间。

## 本轮额外发现并修复

- named producer 迁移后，扫描防串任务仍判断 `source_agent == scan`：改为判断 `ingestion_method == transcript-scan`；
- CLI dedupe 同样只查旧 `source_agent=scan`：改为查 transcript ingestion；
- Dashboard task payload 缺少 updates，导致全局来源筛选无法覆盖任务页；
- System 页缺版本号；版本提升到 0.5.0；
- 验收脚本不再删除固定 `.acceptance`，默认使用随机临时目录。
