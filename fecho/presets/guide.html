Fecho 接入与验收

Fecho 替你记下每天用 agent 做成了什么，每天到点自动出一份日报和口播稿。装一次大约 10 分钟，不用装任何软件包，也不用任何密钥。

它是什么

一条链路，你只需要管第一段和最后一段。

你的电脑① 采集agent 干完活随手记一条；每晚再扫一遍当天对话补漏
服务器② 归属把每条进展对到你名下的 Mobius issue 上
服务器③ 存储每人只看得到自己的记录
服务器④ 整理到点把一天的进展写成日报，按你的写作偏好
网页⑤ 交付日报 + 口播稿；可以直接改，改完它会学

默认每天北京时间 21:00 出日报，你电脑上的扫描提前 15 分钟，也就是 20:45。时间可以自己改。这份指南随时能在 Fecho 左侧「接入指南」里找到。

装之前

四个条件都满足再开始。

账号
能登录 Mobius 的 @feedmob.com 邮箱
电脑
macOS、Windows 10/11 或 Linux，装有 Python 3.9 以上。Mac 和大部分 Linux 自带；Windows 没有的话 agent 会提醒你先装
agent
Codex（ChatGPT 桌面版里的就行）或 Claude Code（桌面版和命令行的 Code 对话都算）。Cursor、Grok、Hermes 暂时只能随手记，不能每晚扫描
Claude Code 用户
在「终端」（Windows 上是 PowerShell）里输入 claude 能正常对话。只在桌面版登录过不算，扫描要用命令行版

安装

主要是 agent 在干，你负责登录、复制 token、勾文件夹。

  1. 把这句话发给你的 agent

    在 Codex 或 Claude Code 里新开一个对话，粘贴：

    读 https://fecho.techmob.net/install ，按里面的步骤帮我接入 Fecho。

  2. 登录，把 token 交给 agent

    agent 会帮你打开网页。用 Mobius 登录，点「生成 token」，把那串 fecho_ 开头的字符复制粘回给 agent。这串只显示一次，别发到群里。

  3. 等 agent 装完，看它的汇报

    它会逐个试着在后台叫醒你电脑上的 agent，每个一行：✓ 表示以后每晚扫它的对话，✗ 表示暂时不扫，后面跟着原因和修法。

    最常见的 ✗：Claude 的命令行版没登录。在终端（Windows 上是 PowerShell）输入 claude 登录（用 CC Switch 的，在 CC Switch 里给 Claude 选一个能用的线路），然后让 agent 把安装那条命令再跑一遍。

  4. 勾选工作文件夹

    回到网页（fecho.techmob.net/onboard），第 3 步里列着你用 agent 干过活的文件夹。只勾工作的。一个都不勾，就什么都不会扫。

  5. 重启 agent 会话

    新接上的工具要重启一次会话才出现。重启后跟 agent 说「调一下 fecho_doctor」，它应该显示你的邮箱。

隐私

  • 只扫你勾选的文件夹。没勾的文件夹，对话连打开都不会打开。
  • 对话原文不离开你的电脑。你电脑上的 agent 读完对话，只把提炼出来的「做成了什么」传上去；工具调用、工具输出一律丢掉。
  • 每个人只看得到自己的记录。admin 能看全员日志，admin 由 Rachel 审批。
  • 写作偏好每人一份，只有你自己看得到，可以随时改或清空。

常见问题

日报页是空的，点「重新生成」提示没有记录

那天确实一条记录都没有，生成不出东西。先检查验收清单里「装完当天」那几项，尤其是工作文件夹有没有勾、随手记能不能进网页。

出日报那会儿电脑合上了 / 没开机

第二天早上电脑一联网，本机采集会先把昨天补扫上去，那天的日报会自动重出。什么都不用做。

agent 说 token 无效或过期

token 连续 7 天没用才会过期。回 onboard 页 再生成一个交给 agent，让它按安装说明重新接一次。

「快速 API」和平时的随手记有什么区别

是给装不了 MCP 的 agent 留的路——服务器上的 bot、网页版 ChatGPT 的 Actions 这种，能发 HTTP 但接不了 MCP。你自己电脑上的 Claude Code、Codex 照常用随手记就行，不用碰它。

它能交两种东西：零散进展（和随手记一样，到点一起整理成日报，不覆盖任何东西）， 或者整篇写好的日报（会顶掉当天那篇）。拿不准就交零散进展。

钥匙是谁的，记录就进谁的账号。几个人共用一个 bot 时每人要填自己那把。 钥匙贴错地方了，回网页再点一次「快速 API」，旧的立刻作废。

工作文件夹自动扫出来一大堆，看着乱

本机会把你用 agent 干过活的文件夹都列出来，方便你挑。没勾的一律不扫， 对话连打开都不会打开，所以列在那里不影响隐私，只是看着杂。

不想要的点那一行的「×」移除掉，本机下次上报不会再把它加回来。 移除错了在列表底下「已移除」里点一下就放回来。

我改过的日报，会不会被自动重出的覆盖掉

不会。改过的日报只有你自己点「重新生成」才会被覆盖，覆盖掉的版本仍然留在「历史版本」里。有新进展时页面会提示你。

写作偏好学偏了

「设置 → 写作偏好」里直接删掉那一行，保存。下次出日报就不按它写了。

想卸载

终端运行 python3 ~/.fecho-cloud/fecho_local.py uninstall（Windows：py -3 "$HOME\.fecho-cloud\fecho_local.py" uninstall）停掉每晚扫描；再让 agent 移除名为 fecho 的 MCP 连接。

已知问题

验收时碰到这些不用单独报，已经记着了。

Cursor、Grok、Hermes 不能每晚扫描。Cursor 的对话本机读不了；Grok bot 不在你电脑上跑；后台叫醒 Hermes 还没实测过。网页上它们的开关是灰的，随手记照常能用。

Claude 桌面版里的普通聊天扫不到。那些聊天存在 Anthropic 服务器上，本机没有记录；桌面版里 Code 标签页的对话能扫。

Windows 和 Linux 的每晚扫描还没在真机上完整验证过。装的时候或第二天没看到扫描结果，请在「反馈」里说一声，附上 status 的输出。

切到英文后，服务器返回的提示和日报正文仍是中文。目前只翻译了界面。

反馈给 Rachel

有任何建议或问题：登录后在 Fecho 左侧「反馈」里直接提，可以粘贴截图，提完能看到处理状态。验收结果或卡住的地方，也可以直接发给 Rachel：

  • 这页清单的截图（左侧有进度）
  • 卡住的话：第几步、日期时间、页面或终端的截图
  • 终端里 python3 ~/.fecho-cloud/fecho_local.py status 的输出（Windows 在 PowerShell 里运行 py -3 "$HOME\.fecho-cloud\fecho_local.py" status）
